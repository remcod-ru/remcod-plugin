# REMCOD — плагин для Codex и Claude Code

Навыки для строительных проектов: сметы и прайсы, отчёты и акты, финансовая аналитика, комплектация и база знаний. Плагин подключается к официальному MCP REMCOD через OAuth; backend и данные приложения в этом репозитории отсутствуют.

## Установка

В Codex добавить этот Git-репозиторий как источник плагинов и установить REMCOD. Если ваша версия CLI поддерживает plugin marketplace:

```bash
codex plugin marketplace add https://github.com/remcod-ru/remcod-plugin.git
codex plugin add remcod@remcod
```

Синтаксис проверен в Codex CLI 0.159.1. Можно клонировать репозиторий и добавить его локальный путь в UI или CLI — `.agents/plugins/marketplace.json` содержит установочный пакет. После установки открыть новую сессию, затем пройти OAuth REMCOD.

В Claude Code:

```text
/plugin marketplace add remcod-ru/remcod-plugin
/plugin install remcod@remcod
```

Нужен аккаунт REMCOD. При подключении войдите в REMCOD и выберите доступную организацию. Не добавляйте API-ключи или пароли в Git, манифесты и чат.

## ChatGPT Web

В разделе **Настройки → Плагины → Добавить** загрузите ZIP из GitHub Release. В архиве должен быть один каталог `remcod/`, внутри него `plugin.json`, `mcp.json` и `skills/`; не архивируйте только содержимое каталога.

Для сборки из клона репозитория:

```bash
node scripts/package-chatgpt.mjs /tmp/remcod-plugin.zip
```

Генератор проверяет, что архив содержит ровно один корневой каталог плагина.

## Что умеет

28 навыков помогают работать с проектами, задачами, графиком, сметами, прайсами, отчётами, актами, деньгами, комплектацией, контрагентами и нативными документами базы знаний. Есть навыки файлов/PDF, шаблонов/операций и 10 предметных ролей.

Фактические операции определяются каталогом вашего MCP-сервера, тарифом и правами. Пакет навыков не обновляет backend. Новые файловые инструменты требуют backend REMCOD 0.4.0 или новее: импорт выбранных файлов в проект и к платежу, проверка вложений отчёта, скачивание документа и PDF сметы/акта/комплектации. Лимит файлов — 5 МБ; сохранение embedded MCP resources зависит от клиента.

Изменения проходят draft → review → apply. Файл отчёта не является автоматически подтверждением оплаты. Запись платежа в REMCOD не выполняет банковский перевод. Экспорт PDF не подписывает акт. В отсутствие инструмента навык должен сообщить об ограничении, а не заявить успех.

## Проверка пакета

Только Node.js 22+, стандартная библиотека, без npm install:

```bash
node scripts/check.mjs
```

Проверка валидирует манифесты, версии, маркетплейсы и навыки; не меняет данные REMCOD и не подтверждает OAuth, бизнес-функции или доступность сервера. При подключении сначала попросите плагин показать доступные проекты, затем прочитать выбранный проект. Мутации тестировать на тестовой организации, с конкретным подтверждением черновика.

Публичный Git-маркетплейс — отдельный способ распространения. Наличие репозитория не означает одобрение в публичном каталоге OpenAI.
