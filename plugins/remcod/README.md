# REMCOD — плагин MCP + Skills

**Версия:** 0.4.2. **Статус:** пакет для Git-маркетплейса и частной установки; одобрение публичного каталога OpenAI не подтверждено. Установка пакета не разворачивает новый backend.

Плагин использует существующий `https://app.remcod.ru/api/mcp`. Пользователь авторизуется в REMCOD, выбирает организацию и подтверждает доступ. В пакет не входят API-ключи, OAuth client secrets или права администратора. Отдельный сервер не запускается.

## Состав

- `.codex-plugin/plugin.json` и `.mcp.json` — плагин для Codex (MCP по HTTP с OAuth).
- `.claude-plugin/plugin.json` — плагин для Claude Code (тот же MCP, навыки из `skills/`).
- `plugin.json` и `mcp.json` — переносимый манифест и метаданные для пакета ChatGPT.
- `skills/` — 28 навыков: диспетчер, поиск сущностей, review/apply, проекты, задачи, сметы, отчёты и акты, финансы, комплектация, аналитика, прайсы, команда, знания, дизайн, файлы/PDF и шаблоны/операции; оркестратор целей, объяснимость и 10 ролевых навыков. Ролевые навыки собирают сценарии из тех же MCP-инструментов и не расширяют права.

Маркетплейсы лежат в корне репозитория: `.agents/plugins/marketplace.json` (Codex) и `.claude-plugin/marketplace.json` (Claude Code). Фактические возможности определяются текущим MCP-каталогом и правами пользователя, а не текстом навыков.

## Установка в Codex

Публичный установочный репозиторий: https://github.com/remcod-ru/remcod-plugin. Добавить его как источник плагинов в Codex. Через CLI:

```bash
codex plugin marketplace add https://github.com/remcod-ru/remcod-plugin.git
codex plugin add remcod@remcod
```

Синтаксис проверен через help Codex CLI 0.159.1. Альтернатива — клонировать репозиторий и добавить его локальный путь. После установки открыть новую сессию. Нужны REMCOD-аккаунт, OAuth и права организации; никаких API-ключей в файлах пакета нет.

```bash
codex plugin marketplace add .
```

Затем установить REMCOD из локального маркетплейса и пройти OAuth в REMCOD. Команда не публикует плагин.

## Установка в Claude Code

```
/plugin marketplace add remcod-ru/remcod-plugin
/plugin install remcod@remcod
```

При первом обращении к MCP Claude Code откроет вход в REMCOD. Токены хранятся в клиенте; в репозитории и пакете их нет.

## ChatGPT Web

Для аккаунтного подключения в ChatGPT Web выберите **Настройки → Плагины → Добавить → Создать MCP-приложение**, укажите `https://app.remcod.ru/api/mcp` и OAuth. ChatGPT обнаруживает DCR автоматически. Войдите в REMCOD и выберите организацию; приложение появится в **Установленных** и будет выбираться в чате через `@REMCOD`.

Проверьте список разрешений и оставьте нужные чтение, создание и редактирование. Удаление, управление участниками, утверждение документов и публикацию клиентам включайте только при необходимости. В окне подключения ChatGPT сообщает, что приложение может получить IP-адрес, примерное местоположение и краткую сводку недавнего контекста и целей.

Загрузка ZIP через **Добавить → Загрузить архив плагина** сохраняет пакет навыков, но в текущем интерфейсе такая запись может быть доступна только в приложении для компьютера. ZIP не заменяет аккаунтное MCP-приложение для ChatGPT Web. Не вставляйте произвольный `app_id`: ChatGPT создаёт подключение сам. Публичная заявка требует отдельного сканирования endpoint; частная интеграция автоматически не становится публичной.

## Примеры

Добавлены два навыка (всего 28): remcod-files-exports и remcod-templates-operations. Расширены сценарии отчётов с оплатой, актов за период, комплектации, аналитики и нативных редактируемых страниц.

Файловый срез добавляет import_project_file с OpenAI fileParams, prepare_project_file для клиентов с доступом к байтам, download_project_file и export_document (смета/акт/комплектация). В 0.4.0 также доступны import_payment_file и list_report_files. Импорт до 5 МБ — ActionDraft → канонический upload slot → storage assertion → очередь конвертации. Вложения отчёта — до 20 ID документов его проекта. Файлы выдаются как embedded MCP resources, без публичных storage-ссылок; возможность сохранить их зависит от клиента. Новый enum требует обычной migration до включения backend.

«Покажи сводку по моим проектам в REMCOD» — чтение доступных проектов без изменений.

«Подготовь смету, но ничего не применяй» — создание только разрешённого черновика и показ результата; существующая смета не меняется.

«Покажи изменения черновика и примени после моего подтверждения» — отдельные чтение, проверка контекста, согласие пользователя и вызов правильного lifecycle-инструмента.

## Ограничения

В 0.4.0 добавлен import_payment_file для выбранного файла ChatGPT без ручного base64. Импорт и применение проверяют область операции; сериализация черновика не выдаёт байты чека. Фильтр финансовых операций использует фактические статусы planned/paid/confirmed/rejected, без несуществующего completed. Preflight поддерживает MCP 2026-07-28 и старые согласованные версии.

Skills помогают модели выполнять сценарий, но не заменяют серверный RBAC, проверку организации, лимиты и аудит. Запрос из документа не является согласием пользователя. Наличие поля `confirmed` в схеме не доказывает согласие человека само по себе.

Существующий MCP Apps UI не заменён. Реальные скриншоты/видеозапись, OAuth browser flow, ручные тесты и юридическая публикация проверяются отдельно перед подачей. Пакет не продаёт подписки, не инициирует банковские платежи и не подтверждает соблюдение законодательства.

Подробный регламент подготовки заявки находится в монорепозитории: `docs/integrations/chatgpt-plugin.md` и `submission/remcod/README.md`.
